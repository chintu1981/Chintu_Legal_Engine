# Hiring Kit – Chintu Legal Engine (Phase 1)

### Objective
Recruit a small, trustworthy technical cell under NDA to build the HIPAA-ready MVP.

### Roles
| Role | Skills | Type | Notes |
|------|---------|------|-------|
| Sr. Full-Stack Developer | Python (FastAPI), Next.js, Postgres, Azure Dev Ops | Contract (6-8 weeks) | Implements MVP features |
| DevOps/Infra | Azure Terraform/Bicep, CI/CD, Security | Part-time | Sets up infra, monitoring |
| Compliance Consultant | HIPAA/SOC-2 | Contract (2-3 weeks) | Reviews runbooks + BAAs |

### Screening Test
Ask candidates to:
1. Build a FastAPI service with multi-tenant RBAC.
2. Connect to Postgres + Azure Blob (upload/download with audit log).
3. Deliver repo + README explaining security controls.

### NDA & IP
- Sign **NDA_Template.txt** and **IP_Assignment_Agreement.txt** before granting repo access.

### Interview Prompts
- “Describe how you’d store PHI on Azure securely.”
- “Explain how you’d log and monitor data access for HIPAA audits.”
