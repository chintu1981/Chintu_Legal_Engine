# Project Charter — Chintu Legal Engine

## Vision
Operational engine to support legal intake, screening, hiring, and project orchestration for mass-tort / plaintiff-side workflows.

## Objectives (Phase 1)
1. Standardize repo and starter API
2. Publish Hiring Kit (Paralegal, Intake Agent, PM)
3. Establish onboarding checklists and NDA
4. Define dev standards and environment

## Out-of-Scope (Phase 1)
- Production DB schemas
- External integrations
- Full intake automations (defer to Phase 2/3)

## Success Criteria
- Repo runs locally (`uvicorn` works)
- Hiring kit is ready to post
- Readme + standards are clear
