# Eligibility Script — Case Type B (v1)

## Purpose
Alternate case type with device-specific filters.

## Disqualifiers (Immediate NO)
- No exposure or wrong device batch/lot
- Out-of-state SOL expired and no tolling

## Questions
1. **Device/lot number** (if known)?
2. **Implant/Use date** and **removal/revision** dates (if any)?
3. **Adverse events** experienced (choose from list + free text)
4. Treating **physician/clinic** known? (Y/N)
5. Prior **class action** participation or settlement? (Y/N)
6. Current **representation**? (Y/N)
7. **State** where procedure/use occurred.

## Scoring (suggested)
- Known affected lot (+3)
- Revision/removal within X months (+2)
- Documented adverse events (+2)
- Not represented (+2)

**Threshold:** ≥6 → Likely Eligible; 4–5 → Review; ≤3 → Decline
