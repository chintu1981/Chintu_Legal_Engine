# Eligibility Script — Case Type A (v1)

## Purpose
Rapid pre-qualification in 3–4 minutes.

## Disqualifiers (Immediate NO)
- Already represented by another firm for this exact matter
- Incident outside statute-of-limitations (check state; if unclear → escalate)
- No product/drug exposure or wrong product

## Questions (Y/N or date-bound)
1. What **product/drug** were you exposed to? (List or free text)
2. Approximate **first exposure / use date**? (MM/YYYY)
3. Any **diagnosis/symptoms** a doctor linked to this? (Y/N → describe)
4. Are you currently **represented** by an attorney for this issue? (Y/N)
5. **State** of exposure / residence at time of exposure?
6. Any **proof** available (medical records, receipts, photos)? (Y/N)
7. Did you **stop using** the product? When?
8. Prior **lawsuit or settlement** for this same matter? (Y/N)

## Scoring (suggested)
- Product match (+2)
- Exposure in window (+2)
- Doctor-linked diagnosis (+3)
- Proof available (+1)
- Not represented (+2)
- No prior settlement (+1)

**Threshold:** ≥6 → Likely Eligible; 4–5 → Edge Case (escalate); ≤3 → Not Eligible

## Next Steps
- If ≥6: send e-sign retainer + HIPAA auth (if needed), open case shell.
- If 4–5: escalate to PM/attorney same day.
- If ≤3: polite decline, log disposition.
